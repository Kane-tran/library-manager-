CSV Format

Your CSV file must have the following columns in order:

#ColumnRequiredExample
1titleYesClean Code
2isbnNo978-0-13-468599-1
3descriptionNoA book about...
4totalCopiesYes3
5publishedYearNo2008
6publisherNoPrentice Hall
7languageNoEnglish
8categoryNameNoProgramming
9authorNamesNoRobert C. Martin;John Doe
Multiple authors must be separated by semicolons (;). Categories and authors are created automatically if they don't exist.
